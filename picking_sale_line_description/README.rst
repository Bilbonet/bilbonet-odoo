This module extends ``stock.move`` with a read-only related field that
takes the sales line description from ``sale.order.line.name``.

In delivery operations on the picking form, it adds that value to the
``Operations`` lines (``move_ids_without_package``) as an optional
column hidden by default, so users can show it when they need to compare
the warehouse move with the original sales line description.

Usage
=====

To use this module:

- Create and confirm a sales order with a description on the sales order
  line.
- Open the generated delivery order.
- Go to the ``Operations`` tab.
- Open the column selector for the operations list and enable
  ``Sale Line Description``.

The column shows the value stored in the linked sales order line
description for each stock move.

Known issues / Roadmap
======================

The sales line description is only added to the ``Operations`` list on
the picking form (``move_ids_without_package``).

It is not added to the ``Detailed Operations`` lines or to other stock
move views.
