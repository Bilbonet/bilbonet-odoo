This module extends ``partner_email_role_assignment`` to support
role-based email recipients for stock pickings.

It allows users to mark child contacts as delivery email recipients from
the partner form and updates the standard stock delivery email template
so those contacts are automatically included when sending pickings by
email.

Use Cases / Context
===================

Some customers need delivery notes and outbound picking communications
to reach different recipients than sales or invoicing. This module
covers that gap by adding a dedicated picking email role on partner
contacts.

Installation
============

No additional installation steps are required.

Configuration
=============

No extra configuration is needed for standard usage.

Usage
=====

To use this module, you need to:

- Open a customer and go to the *Contacts & Addresses* tab.
- Edit or create a child contact with an email address and enable *Used
  like mail for picking*.
- Save the contact and return to the parent partner.
- Check the *Mail Addresses* tab. The marked contact is listed in the
  *Pickings* section.
- Send a delivery order by email with the standard *Send by Email*
  action. The stock delivery template will include the marked picking
  contacts in ``partner_to``.
