This module extends Point of Sale to require cashier selection before
opening the payment screen.

When a POS user clicks *Payment*, the standard Odoo cashier selection
popup is shown. The payment flow continues only after a cashier is
selected, using the standard ``pos_hr`` employee and PIN behavior.

   Only for development or testing purpose, do not use in production.

Use Cases / Context
===================

Some businesses need the cashier responsible for payment to be selected
explicitly at the payment step. This avoids completing payments under an
implicit cashier or under the cashier selected earlier in the session.

This module enforces that confirmation while reusing the standard Odoo
16 cashier selection behavior from ``pos_hr``.

Installation
============

No additional installation steps are required.

Configuration
=============

Configure the standard Odoo POS employee login features provided by
``pos_hr``.

At minimum:

1. Enable employee login/cashier selection on the POS configuration.
2. Configure the employees allowed to work in the POS session.
3. Configure employee PINs when cashier authentication is required.

Usage
=====

To use this module:

1. Open a Point of Sale session.
2. Add products to the current order.
3. Click *Payment*.
4. Select the cashier in the popup.
5. If the selected cashier requires a PIN, enter it.
6. Continue with the standard payment process.

Canceling the cashier popup keeps the order on the product screen.
