This module extends OCA sales commissions to support product manager
commissions based on the product category of each sale order line.

Product categories can be configured with one or more commission agents.
When a product is added to a sale order, the agents configured on its
category are added to the sale order line commissions together with the
standard agents provided by ``sale_commission_oca``.

Category agents are not duplicated if the same agent is already present
on the sale order line through another commission rule.

Use Cases / Context
===================

Some commercial processes require commissions for a "Product Manager"
role. These commissions depend on the product being sold rather than
only on the customer, delivery address, salesperson, or commercial zone.

This module centralizes that configuration on product categories so
sales order line commissions can be generated automatically from the
sold product.

Installation
============

No additional installation steps are required.

Configuration
=============

To configure product manager commissions:

- Go to *Sales > Products > Product Categories*.
- Open the product category that should generate product manager
  commissions.
- In the *Product Manager Agents* group, add the commission agents
  responsible for that category.
- Review the proposed commission for each agent and change it if needed.

Agents must be valid commission agents.

Usage
=====

To use this module:

- Configure product manager agents on the relevant product categories.
- Create or edit a sale order.
- Add a product whose category has product manager agents configured.
- Open the commission agents of the sale order line to review the
  generated agents and commissions.

When the product of a sale order line changes, the line commissions are
recomputed and the product category agents are updated.

If the same agent is already assigned to the line by another commission
rule, the product category agent line is not added again.
