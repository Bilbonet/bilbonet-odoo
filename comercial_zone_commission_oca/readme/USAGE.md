To use this module:

- Configure commercial zones and their zone agents.
- Assign a commercial zone to a customer.
- Create a sales order for that customer.

The agents configured on the customer's commercial zone are added to the sales
order line commission agents when the commission agents are computed.

Existing sales orders are not automatically updated when commercial zone
configuration changes. Use the standard *Regenerate agents* button on the sales
order when existing draft quotations must apply updated commission settings.
